# React Projects

A collection of small projects built with React as part of my journey to becoming a better frontend developer.

This repository is where I practice React concepts, explore new ideas, improve my problem-solving skills, and turn what I learn into working applications.

## Projects

### 1. FAQ Accordion

An interactive FAQ accordion that allows users to expand and collapse questions to view their answers.

**Concepts practiced:**
- React components
- Props and state
- Event handling
- Conditional rendering
- Reusable components
- Responsive UI design

**Technologies:** React, JavaScript, Vite, Tailwind CSS

### 2. Random Color Generator

A simple application that generates random colors and displays their color values.

**Features:**
- Generate random HEX colors
- Generate random RGB colors
- Generate random colors using either format
- Display the generated color
- Copy color values

**Technologies:** React, JavaScript, Vite, Tailwind CSS

### 3. Star Rating

An interactive star rating application that allows users to rate an experience by selecting stars, see feedback based on their selection, and submit or reset their rating.

**Features:**
- Select a rating from 1 to 5 stars
- Hover over stars for interactive feedback
- Display a message based on the selected rating
- Submit a rating
- Reset the selected rating
- Responsive user interface

**Concepts practiced:**
- React components
- `useState` Hook
- Event handling (`onClick`, `onMouseEnter`, `onMouseLeave`)
- Conditional rendering
- Array mapping with `.map()`
- Dynamic CSS classes
- Basic form interaction

**Technologies:** React, JavaScript, Vite, CSS
### 4. Image Slider

An interactive image slider that allows users to navigate through a collection of images using previous and next buttons.

**Features:**

- Display images in a slider.
- Navigate between images using previous and next buttons.
- Smooth image transitions.
- Responsive user interface.

**Concepts practiced:**

- React components
- `useState` Hook
- Event handling
- Conditional rendering
- Array indexing
- Dynamic image rendering

**Technologies:** React, JavaScript, Vite, CSS

## Running a Project Locally

1. Clone the repository:

```bash
git clone https://github.com/Melala-9716/react-projects.git
```

2. Navigate into the project you want to run:

```bash
cd react-projects/faq-accordion
```

3. Install dependencies:

```bash
npm install
```

4. Start the development server:

```bash
npm run dev
```

To run another project, navigate into its folder and repeat the installation and development steps.
