]# FAQ Accordion

An interactive FAQ accordion built with React. Users can click on questions to expand or collapse them and view their corresponding answers.

## Features

- Display a list of frequently asked questions.
- Click a question to reveal its answer.
- Expand and collapse answers interactively.
- Keep the interface simple and user-friendly.
- Responsive user interface.

## Technologies Used

- React
- JavaScript (JSX)
- Vite
- Tailwind CSS

## Concepts Practiced

- React components
- Props
- `useState` Hook
- Event handling (`onClick`)
- Conditional rendering
- Rendering lists with `.map()`
- Importing and exporting modules
- Reusable components
- Responsive UI design

## Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/Melala-9716/react-projects.git
```

### 2. Navigate to the project folder

```bash
cd react-projects/faq-accordion
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

Open the local URL provided by Vite in your browser.

## What I Learned

Through this project, I practiced building interactive React components, managing component state with `useState`, handling click events, and displaying content conditionally.

It helped me understand how React updates the user interface when the state changes.
